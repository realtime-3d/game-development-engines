# PC & Console Game Engines

Shipping on PC (Steam, Epic Games Store, itch.io) is straightforward in almost every engine. Shipping on consoles (**Nintendo Switch, PlayStation 4/5, Xbox Series X/S**) has strict licensing, NDA, and certification requirements.

- **Last Verified:** 2026-11-16

## Console & PC Support Matrix

| Engine | PC (Win / Mac / Linux) | Official First-Party Console Export | Requirements / Notes |
| --- | --- | --- | --- |
| **[Unreal Engine](../engines/unreal-engine.md)** | Yes | Yes (PS, Xbox, Switch) | Registered console developer approval from Sony/Microsoft/Nintendo |
| **[Unity](../engines/unity.md)** | Yes | Yes (PS, Xbox, Switch) | **Unity Pro** ($2,310/seat/yr) + platform-holder approval |
| **[Defold](../engines/defold.md)** | Yes | Yes (PS, Xbox, Switch) | Free engine; requires platform-holder approval |
| **[GameMaker](../engines/gamemaker.md)** | Yes | Yes (PS, Xbox, Switch) | **Enterprise** ($79.99/mo) + platform-holder approval |
| **MonoGame** | Yes | Yes (PS, Xbox, Switch) | Free framework; requires platform-holder approval |
| **[Godot](../engines/godot.md)** | Yes | Via Third-Party Middleware | W4 Games, Lone Wolf Technology, or custom NDA C++ builds |
| **CRYENGINE** | Win / Linux | Yes | Registered console developer approval |

> **Important:** "Supports consoles" never means any developer can click "Export to Switch/PS5" on day one. Every console manufacturer requires company/project approval and NDA signing before granting access to console SDKs.
