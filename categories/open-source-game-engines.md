# Open-Source Game Engines

Open-source game engines give you full access to the source code under an OSI-approved license (such as MIT, Apache 2.0, zlib, or Ms-PL), protecting your studio from vendor lock-in or unexpected pricing changes.

- **Last Verified:** 2026-11-16

## Best Open-Source Game Engines

| Engine | License | 2D / 3D | Languages | Has GUI Editor? |
| --- | --- | --- | --- | --- |
| **[Godot](../engines/godot.md)** | MIT | 2D & 3D | GDScript, C#, C++ | Yes |
| **[GDevelop](../engines/gdevelop.md)** | MIT | 2D & light 3D | Visual Events, JS | Yes |
| **[Phaser](../engines/phaser.md)** | MIT | 2D (Web) | JavaScript, TypeScript | Optional paid editor |
| **[Bevy](../engines/bevy.md)** | MIT / Apache 2.0 | 2D & 3D | Rust | In development |
| **[Ren'Py](../engines/renpy.md)** | MIT | 2D (Visual Novel) | Ren'Py Script, Python | Launcher + Script |
| **Cocos Creator** | Open-source core | 2D & 3D | TypeScript, C++ | Yes |
| **Stride** | MIT | 2D & 3D | C# | Yes (Windows) |
| **O3DE** | Apache 2.0 / MIT | 3D | C++, Lua, Script Canvas | Yes |
| **MonoGame** | Ms-PL | 2D & 3D | C# | No (Code-first) |
| **LÖVE (Love2D)** | zlib | 2D | Lua | No (Code-first) |
| **libGDX** | Apache 2.0 | 2D & 3D | Java, Kotlin | No (Code-first) |
| **Three.js / Babylon.js / PixiJS** | MIT / Apache 2.0 | 2D / 3D (Web) | JS, TypeScript | Library / Web tools |

> **Note on "Source-Available" vs "Open Source":** [Unreal Engine](../engines/unreal-engine.md) and [Defold](../engines/defold.md) provide public source code, but their licenses include commercial/redistribution restrictions (royalties or non-compete clauses), so they are classified as **source-available** rather than OSI open-source.
