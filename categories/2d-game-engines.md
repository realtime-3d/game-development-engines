# Best 2D Game Engines

2D games benefit from engines with native pixel coordinates, fast sprite batching, tilemap editors, and clean 2D physics—rather than forcing 2D into a heavy 3D pipeline.

- **Last Verified:** 2026-11-16

## Top 2D Game Engines

| Engine | Languages / Workflow | Open Source | Pricing | Best For |
| --- | --- | --- | --- | --- |
| **[Godot](../engines/godot.md)** | GDScript, C# | Yes (MIT) | Free, 0% royalty | General 2D, pixel art, platformers |
| **[GameMaker](../engines/gamemaker.md)** | GML, GML Visual | No | Free / $99.99 once | Action 2D, pixel art, top-down |
| **[Unity](../engines/unity.md)** | C#, Visual Scripting | No | Free <$200k/yr | Mobile 2D, consoles, large asset ecosystem |
| **[GDevelop](../engines/gdevelop.md)** | Event Sheets, JS | Yes (MIT) | Free (MIT) | No-code 2D, browser, rapid jams |
| **[Defold](../engines/defold.md)** | Lua | Source-available | Free forever | Mobile 2D, HTML5, tiny builds, consoles |
| **[Phaser](../engines/phaser.md)** | JavaScript, TypeScript | Yes (MIT) | Free | Browser / HTML5 2D games |
| **LÖVE (Love2D)** | Lua | Yes (zlib) | Free | Code-first 2D indie games (*Balatro*) |
| **MonoGame** | C# | Yes (Ms-PL) | Free | Code-first 2D cross-platform (*Celeste*, *Stardew Valley*) |
| **HaxeFlixel** | Haxe | Yes (MIT) | Free | Retro pixel-art & web 2D (*Friday Night Funkin'*) |
| **PICO-8** | Lua | No | $14.99 once | 128×128 retro fantasy console |
