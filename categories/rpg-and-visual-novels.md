# Game Engines for RPGs, Visual Novels, Pixel Art & Platformers

Genre-specific and 2D-specialized engines can save months of boilerplate work compared to building RPG inventories, dialogue trees, or pixel-perfect platformer physics from scratch.

- **Last Verified:** 2026-11-16

## By Genre

### Visual Novels & Narrative Games
- **[Ren'Py](../engines/renpy.md):** The most widely used engine for visual novels. Free (MIT), built-in save/load, rollback, localization, and Python extensibility.
- **[Godot](../engines/godot.md) (with Dialogic):** Best if your visual novel blends with 2D/3D exploration or action mechanics.

### RPGs (JRPGs, Tactical, Action RPGs)
- **RPG Maker MZ:** Built specifically for classic tile-based JRPGs with a ready-made database, turn-based battle system, and event commands ($69.99-$79.99 one-time).
- **[Godot](../engines/godot.md) / [GameMaker](../engines/gamemaker.md) / [Unity](../engines/unity.md):** Better for action RPGs, real-time combat, or custom UI/mechanics (*Cassette Beasts* in Godot, *Undertale* in GameMaker).

### Pixel Art & 2D Platformers
- **[Godot](../engines/godot.md):** Dedicated pixel-coordinate 2D renderer, TileMapLayer, and clean integer scaling.
- **[GameMaker](../engines/gamemaker.md):** Fast 2D room/sprite workflow (*Pizza Tower*, *Hyper Light Drifter*).
- **MonoGame:** Code-first C# framework behind *Celeste* and *Stardew Valley*.
- **PICO-8:** $14.99 fantasy console with strict 128×128 16-color constraints, well suited to focused retro platformers (*Celeste Classic*).
