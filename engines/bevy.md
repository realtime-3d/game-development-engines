# Bevy

**Bevy** is a data-driven **Entity Component System (ECS)** game engine built in **Rust**, licensed under MIT or Apache 2.0.

- **Latest Version Checked:** Bevy 0.15+
- **License:** [MIT OR Apache-2.0](https://bevyengine.org/)
- **Open Source:** Yes
- **Last Verified:** 2026-11-16

## Best For

- Rust developers building 2D or 3D games from code
- Performance-sensitive simulations, strategy games, and procedural systems
- Developers who prefer clean ECS architecture over OOP scene trees

## Languages & Visual Scripting

- **Language:** Rust
- **Visual Scripting:** None (code-first; official visual editor is in active development).

## 2D & 3D Capabilities

- **2D:** Sprites, texture atlases, tilemaps, 2D camera, and community physics (`avian2d`, `bevy_rapier2d`).
- **3D:** wgpu-based PBR renderer supporting Vulkan, Metal, DirectX 12, and WebGPU/WebGL2.

## Editor & Target Platforms

- **Development OS:** Windows, macOS, Linux
- **Export targets:** Windows, macOS, Linux, Web (WebAssembly / WebGPU), Android, iOS

## Pricing & License Terms

- **Price:** $0 forever ([Bevy Engine](https://bevyengine.org/)).
- **Royalties:** 0%.
- **License:** Dual-licensed MIT / Apache 2.0.

## Pros & Limitations

**Pros:**
- Clean, ergonomic ECS design in Rust with strong compile-time safety.
- Permissive MIT/Apache 2.0 license with zero royalties.
- Active, fast-moving open-source community.

**Limitations:**
- No built-in GUI editor yet (code-first workflow).
- Breaking API changes between minor releases while approaching 1.0.
- No official console export targets.
