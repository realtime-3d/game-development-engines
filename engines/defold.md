# Defold

**Defold** is a lightweight, source-available cross-platform 2D and 3D game engine using **Lua**, backed by the non-profit **Defold Foundation**.

- **Latest Version Checked:** Defold 1.9.x
- **License:** [Defold License](https://defold.com/license/) (Apache 2.0-derived, source-available)
- **Open Source:** Source-available (cannot be resold as a competing commercial engine, 100% free for game dev)
- **Last Verified:** 2026-11-16

## Best For

- High-performance 2D mobile and HTML5 games with tiny binary sizes
- Indie teams wanting free native console support (Switch, PlayStation, Xbox)
- Developers who prefer Lua and component-based architecture

## Languages & Visual Scripting

- **Primary Language:** Lua
- **Native Extensions:** C / C++ / Objective-C / Java for platform SDKs and performance-critical modules.
- **Visual Scripting:** None (code-driven).

## 2D & 3D Capabilities

- **2D:** Mature 2D rendering, Spine/atlas support, GUI layouts, and Box2D physics.
- **3D:** Native 3D mesh, PBR material, and physics support.

## Editor & Target Platforms

- **Editor runs on:** Windows, macOS, Linux
- **Export targets:** Android, iOS, Windows, macOS, Linux, Web (HTML5/Wasm), Nintendo Switch, PlayStation 4/5, Xbox

> **Console note:** Console exports are officially supported at no extra engine fee once you have platform-holder developer approval.

## Pricing & License Terms

Per the [Defold License](https://defold.com/license/) and [Defold Product](https://defold.com/product/):

- **Price:** $0 forever (charter-guaranteed by the Defold Foundation).
- **Royalties:** 0%.

## Pros & Limitations

**Pros:**
- Extremely small runtime footprint and fast Web/mobile load times.
- 100% free forever, including official console support (for approved console devs).
- Proven stability in commercial mobile games.

**Limitations:**
- Smaller community and fewer tutorials than Unity or Godot.
- No visual scripting; Lua-only for gameplay.
- Source-available Defold License is not an OSI-approved open-source license (though source is public on GitHub).
