# Ren'Py

**Ren'Py** is a free, open-source visual novel and narrative game engine powered by **Python** and a human-readable dialogue scripting language.

- **Latest Version Checked:** Ren'Py 8.x
- **License:** [MIT License](https://www.renpy.org/doc/html/license.html) (with LGPL components)
- **Open Source:** Yes
- **Last Verified:** 2026-11-16

## Best For

- Visual novels and branching narrative games
- Dating sims and story-heavy RPGs
- Writers and solo creators with little or no programming background

## Languages & Visual Scripting

- **Ren'Py Script:** Simple indentation-based syntax for dialogue, branching choices, character sprites, and audio.
- **Python:** Full Python 3 support embedded for custom mini-games, stats, and UI screens.

## 2D & 3D Capabilities

- **2D:** Built for 2D character portraits, backgrounds, animated transforms (ATL), and customizable UI screens.
- **3D:** 3D camera stage for parallax depth effects; not a 3D game engine.

## Editor & Target Platforms

- **Editor / Launcher runs on:** Windows, macOS, Linux
- **Export targets:** Windows, macOS, Linux, Android, iOS, Web (HTML5/Wasm)

## Pricing & License Terms

Per the [Ren'Py License](https://www.renpy.org/doc/html/license.html):

- **Price:** $0, 100% free for commercial and non-commercial releases.
- **Royalties:** 0%.

## Pros & Limitations

**Pros:**
- Fastest way to ship a commercial visual novel with built-in save/load, rollback, accessibility, and localization.
- Completely free and open-source with zero royalties.
- Extensible with Python when you need custom mechanics.

**Limitations:**
- Specialized for narrative/2D UI games; not suitable for real-time action or 3D games.
- Console ports require third-party porting partners.
