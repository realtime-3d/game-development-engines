# Construct 3

**Construct 3** is a browser-based 2D game engine developed by Scirra that uses a visual event-sheet workflow alongside optional JavaScript and TypeScript scripting.

- **Latest Version Checked:** Construct 3
- **License:** Proprietary (Subscription)
- **Open Source:** No
- **Last Verified:** 2026-11-16

## Best For

- Non-programmers and beginners building 2D games
- Web/HTML5 games, mobile games, and rapid prototypes
- Classrooms and Chromebooks (runs entirely in the browser, offline-capable PWA)

## Languages & Visual Scripting

- **Visual Scripting:** Event sheets (Condition → Action), polished and fast to author.
- **Scripting:** Optional JavaScript and TypeScript integration directly inside projects.

## 2D & 3D Capabilities

- **2D:** Full-featured 2D engine with Box2D physics, tilemaps, timeline animations, and built-in image/animation editor.
- **3D:** 2D-first engine with basic 3D camera, 3D shape, and mesh distortion features (not a full 3D PBR engine).

## Editor & Target Platforms

- **Editor runs on:** Web browser (Windows, macOS, Linux, ChromeOS)
- **Export targets:** Web (HTML5), Windows, macOS, Linux, Android, iOS, Xbox (via UWP/WebView2)

## Pricing & License Terms

Per [Construct 3 Personal Plans](https://www.construct.net/en/make-games/buy-construct-3/personal-plans):

- **Free Edition:** Limited to 25 events, non-commercial use only.
- **Personal Subscription:** ~$15.99/month or ~$119/year (0% royalties; commercial rights included).

## Pros & Limitations

**Pros:**
- Zero installation, runs smoothly in any modern browser, including Chromebooks.
- Very clean event-sheet UX and fast HTML5 exports.
- Direct mixing of event sheets with JavaScript and TypeScript.

**Limitations:**
- Subscription required for anything beyond 25 events or commercial release.
- Proprietary, closed-source engine.
- Limited 3D capabilities.
