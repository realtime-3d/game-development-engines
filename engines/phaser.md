# Phaser

**Phaser** is a fast, MIT-licensed 2D HTML5/WebGL game framework for JavaScript and TypeScript developers.

- **Latest Version Checked:** Phaser 3.8x / Phaser 4
- **License:** [MIT License](https://github.com/phaserjs/phaser)
- **Open Source:** Yes
- **Last Verified:** 2026-11-16

## Best For

- Browser-based 2D games (Poki, CrazyGames, itch.io, Discord Activities)
- Web developers already comfortable with JavaScript or TypeScript
- Interactive web experiences, playable ads, and educational games

## Languages & Visual Scripting

- **Languages:** JavaScript, TypeScript
- **Visual Scripting:** None built into the free framework; optional paid **Phaser Editor** provides visual scene layout.

## 2D & 3D Capabilities

- **2D:** High-performance WebGL and Canvas 2D rendering, Arcade Physics, Matter.js physics, tilemaps, tweens, and audio.
- **3D:** Strictly 2D (use Three.js or Babylon.js for 3D web games).

## Editor & Target Platforms

- **Editor / Dev environment:** Any OS (Windows, macOS, Linux, Web) with your preferred code editor (VS Code, etc.)
- **Export targets:** Web browsers natively; Desktop (Windows, macOS, Linux) via Electron/NW.js; Mobile (Android, iOS) via Capacitor/Cordova.

## Pricing & License Terms

- **Framework:** 100% free and open-source under the **MIT License** ([Phaser](https://phaser.io/)). Zero royalties.
- **Optional Tooling:** Phaser Editor has optional paid plans for visual scene editing.

## Pros & Limitations

**Pros:**
- Instant browser startup and tiny web bundle sizes compared to WebAssembly engines.
- Complete TypeScript definitions and standard Vite/npm workflow.
- Large community and thousands of official code examples.

**Limitations:**
- Code-first framework with no free built-in visual scene editor.
- Not designed for native console releases.
- 2D only.
