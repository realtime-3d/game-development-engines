# GDevelop

**GDevelop** is an open-source, cross-platform 2D and 3D game engine built around a no-code **event sheet** system (with optional JavaScript extensions).

- **Latest Version Checked:** GDevelop 5.x
- **License:** [MIT License](https://github.com/4ian/GDevelop) (Core engine & editor)
- **Open Source:** Yes
- **Last Verified:** 2026-11-16

## Best For

- Complete beginners and non-programmers
- Educators, students, and rapid game-jam prototyping
- 2D web, mobile, and desktop games, plus lightweight/stylized 3D games

## Languages & Visual Scripting

- **Visual Events:** Condition/Action event sheets that require zero coding.
- **JavaScript:** Optional JavaScript code blocks and custom extensions for advanced logic.

## 2D & 3D Capabilities

- **2D:** Comprehensive 2D behaviors (Platformer, Top-down, Physics 2.0, Pathfinding), built-in Piskel sprite editor, and particle systems.
- **3D:** Native 3D objects, 3D models, and 3D behaviors built into the same event-sheet workflow; best suited for lightweight or stylized 3D rather than heavy AAA scenes.

## Editor & Target Platforms

- **Editor runs on:** Windows, macOS, Linux, Web browser, Android
- **Export targets:** Web (HTML5), Windows, macOS, Linux, Android, iOS

> **Console note:** No native out-of-the-box console exports.

## Pricing & License Terms

Per [GDevelop's official pricing](https://gdevelop.io/pricing):

- **Free Tier ($0):** Full access to the open-source MIT engine, 2D/3D tools, and manual local exports with **0% royalties** and commercial rights. Includes basic cloud packaging quotas.
- **Paid Subscriptions (Silver / Gold, ~$4.99–$9.99/mo):** Optional cloud services — higher daily one-click cloud builds (Android/desktop), more cloud project storage, and unlimited leaderboards/player feedback.

## Pros & Limitations

**Pros:**
- Genuinely free and open-source (MIT) with commercial rights even on the free tier.
- Runs in a web browser, on desktop, or even on Android tablets.
- Extremely low barrier to entry with built-in behaviors and asset store.

**Limitations:**
- Large projects using event sheets can become harder to organize than text code.
- Cloud one-click packaging has daily limits on the free tier (though local/manual exports are unlimited).
- 3D tooling is newer and less capable than Godot, Unity, or Unreal.
